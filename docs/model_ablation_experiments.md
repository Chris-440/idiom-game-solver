# 模型容量、状态表示与完整图 PPO 消融实验

> 状态：研究记录与服务器实验计划  
> 实验日期：2026-08-10  
> 适用代码基线：`main` 分支 `d4f5e655` 及其后续文档提交

## 1. 研究问题

当前 PPO 网络使用当前成语作为单 Query，对最近 64 个历史成语做 Cross-Attention，再通过点积策略头和独立价值头输出策略与价值。正式配置为：

- `idiom_dim = 384`；
- `n_heads = 4`；
- `n_layers = 3`；
- 字符 embedding 维度为 64；
- 完整词表下可训练参数约 3,996,866；
- 历史窗口为最近 64 个先前成语；
- 最大候选动作数为 600。

本轮实验回答两个相互独立的问题：

1. 当前网络是否存在明显容量冗余，较小网络能否保留有效策略能力？
2. 价值头只读取当前状态编码、不直接读取剩余候选集合，是否造成可避免的价值估计误差？

结论需要区分为三类：代码结构事实、精确微型图证据和完整图 PPO 证据。前两类不能自动外推为正式训练的最终胜率。

## 2. 当前结构核查

### 2.1 价值头与候选集合

当前前向过程可概括为：

$$
z_t=f_{\text{history}}(u_t,H_t,p_t),
$$

$$
V(s_t)=f_{\text{value}}(z_t),
$$

$$
\pi(a\mid s_t)\propto\exp(z_t^\top e_a/T),\quad a\in A(s_t).
$$

候选集合只参与策略 logits 计算，没有进入状态编码或价值头。因此，在固定当前成语、历史和玩家标识时，替换整个 `candidate_ids/candidate_mask`，价值输出在数学上不会变化。

对正式 checkpoint 的干预测试也得到一致结果：替换整个候选集合后，价值最大绝对变化为 0。这个结论是结构事实，而不是训练偶然。

### 2.2 历史顺序

模型没有位置 embedding，历史作为被掩码的 Key/Value 集合。对 64 个历史成语进行排列后：

- 价值最大变化约 $5.96\times10^{-8}$；
- logits 最大变化约 $5.72\times10^{-6}$。

因此当前实现近似严格地把历史视为集合，而不是有序序列。

### 2.3 玩家 embedding

翻转绝对玩家标识 P0/P1 后：

- 价值平均绝对变化约 0.0064；
- logits 平均绝对变化约 0.162。

玩家 embedding 对策略影响明显大于对价值影响。该现象值得后续消融，但不能仅凭该测试判断它有害。

## 3. 资源与 checkpoint 回归

在 CPU 环境中成功完成：

- 加载 iteration 1500 checkpoint，参数严格匹配；
- 数据图包含 26,108 个节点、4,215 个字符（含 PAD）；
- 200 局对 Random：100%，Wilson 95% CI 约为 [98.1%, 100%]；
- 200 局对固定 Q-table：88.5%，Wilson 95% CI 约为 [83.3%, 92.2%]；
- 8 局真实 rollout 加一次 PPO 更新：147 个决策样本，无截断轨迹。

一次小批量 PPO 更新的代表性指标：

| 指标 | 数值 |
|---|---:|
| total loss | 0.1078 |
| policy loss | -0.0114 |
| value loss | 0.2596 |
| entropy | 0.2113 |
| grad norm | 1.8598 |
| clip fraction | 0.0136 |
| approximate KL | 0.0167 |

CPU 足以执行回归、消融与短训练，但不适合直接复现 15,000 轮、每轮 512 局的正式训练。

## 4. 跨子图精确实验

### 4.1 子图套件

最初的 14 节点微型图显示候选感知价值头明显改善价值预测，但单张图可能放大特定环结构。因此正式消融改为 18 张真实成语子图，以图为主要实验单位。

| 图属性 | 范围 |
|---|---:|
| 节点数 | 12–16 |
| 有向边数 | 22–45 |
| 平均出度 | 1.79–3.00 |
| 最大强连通分量占比 | 14%–100% |
| 精确可达状态数 | 156–10,755 |
| 非终局决策状态数 | 107–9,969 |

每张图都来自真实四字成语和严格尾字—首字连接。所有状态使用精确 minimax 生成胜负价值与最优动作集合。

### 4.2 防止泄漏的协议

- 排除无合法动作的终局状态，避免模型只凭空候选集合识别终局；
- 训练、验证、测试按精确状态划分；
- 验证集用于早停，测试集不参与模型选择；
- 每图最多抽取 1,500 个训练状态，避免大图支配宏平均；
- 配对模型使用相同数据划分和训练预算；
- 主要置信区间以 18 张图为独立单位 bootstrap；
- 第二次状态划分只作重复性检查，不把同图的两个划分当成两张独立图。

### 4.3 历史截断与状态混叠

若两个精确状态具有相同当前成语、可见历史和玩家标识，但 minimax 胜负标签不同，则当前观测发生状态混叠。候选集合可以减少一部分混叠，但不能保证唯一恢复完整已用集合。

候选集合减少量与价值准确率改善呈中等正相关：

- 历史 3：相关系数约 0.46；
- 历史 6：相关系数约 0.51。

高强连通、高循环图的短历史混叠最严重；弱连通、接近单向推进的图即使只观察最近 3 步，也可能没有混叠。

## 5. 网络容量实验

| 模型 | 完整词表估算参数量 | 短历史价值准确率 | 最优动作准确率 | CPU 前向 B=32 |
|---|---:|---:|---:|---:|
| 384×3 | 3,996,866 | 75.8% | 97.9% | 45.6 ms |
| 128×1 | 444,354 | 87.4% | 98.4% | 11.0 ms |
| 64×1 | 322,242 | 87.0% | 99.2% | 约 9–10 ms |
| 128×1 候选感知 | 452,610 | 88.5% | 97.9% | 12.9 ms |

候选感知价值头将以下信息与历史状态拼接：

$$
[z_t;\operatorname{MaskedMean}(\{e_a:a\in A(s_t)\});\log(1+|A(s_t)|)].
$$

实验说明：

- 微型图的局部最优动作排序不需要 384×3 容量；
- 128×1 是比 64×1 更稳妥的缩小点；
- 宽模型在小数据、固定优化预算下更难训练；
- 这不能证明 384×3 的最终上限更低，只能否定“必须使用 384×3 才有足够容量”的必要性。

## 6. 候选感知价值头的跨图结果

以下区间以 18 张图为独立单位：

| 历史状态 | 128×1 原结构价值准确率 | 候选感知 | 配对提升及 95% CI | MSE 降低及 95% CI |
|---|---:|---:|---:|---:|
| 最近 3 步 | 87.4% | 88.5% | +1.10pp [-0.46,+2.65] | 0.070 [0.042,0.102] |
| 最近 6 步 | 89.6% | 93.8% | +4.27pp [1.88,7.15] | 0.144 [0.078,0.220] |
| 完整历史 | 92.4% | 96.0% | +3.55pp [1.20,6.66] | 0.122 [0.063,0.189] |

正确解释是：历史 3 的分类准确率区间跨 0，不能声称显著改善；三种历史设置下价值 MSE 都稳定下降；完整历史仍改善，说明候选池化还提供优化捷径或归纳偏置；策略准确率普遍接近饱和，候选价值头没有稳定改善动作标签。

## 7. 完整 26,108 节点图的短 PPO A/B

### 7.1 协议

比较 128×1 原结构和 128×1 候选感知价值头：

- 策略编码器、字符 embedding 和温度参数使用相同初始化；
- 只有价值头结构不同；
- 3 个独立随机种子；
- 每模型 50 轮，每轮 32 局；
- 每种子最终进行 400 局对 Random、400 局对 Q-table、400 局模型直接对局；
- 总训练局数为 9,600。

### 7.2 结果

| 种子 | 原结构 vs Random | 候选感知 vs Random | 候选感知直接对原结构 |
|---|---:|---:|---:|
| 20260810 | 96.5% | 88.8% | 41.8% |
| 20260811 | 93.3% | 82.5% | 81.3% |
| 20260812 | 81.3% | 94.5% | 51.5% |
| 平均 | 90.3% | 88.6% | 58.2% |

| 指标 | 原结构 | 候选感知 |
|---|---:|---:|
| 最近 10 轮价值损失 | 0.084 | 0.087 |
| 最近 10 轮策略损失 | 0.012 | 0.016 |
| 平均训练时间/种子 | 144 s | 171 s |
| 平均模型决策轨迹长度 | 46.8 | 50.8 |
| 截断比例 | 0% | 0% |
| 对 Q-table 平均胜率 | 1.0% | 0.9% |

短 PPO 没有给出候选感知结构的稳定胜率优势：

- 对 Random 的配对差异为 -7.8、-10.8、+13.3 个百分点，方向不稳定；
- 直接对局为 41.8%、81.3%、51.5%，种子异质性很大；
- 两者对 Q-table 都接近 1%，50 轮仍处于早期 curriculum；
- 候选感知训练开销增加约 19%。

因此，精确监督中的价值拟合优势没有在完整图早期 PPO 中稳定转化为策略胜率。

可能原因：PPO 的 GAE 回报随策略变化；候选池化把数百个候选 embedding 接入价值损失，梯度会回传到与策略共享的字符 embedding；价值分支可能改变早期探索分布；对 Random 胜率和模型直接对局存在非传递性；50 轮不足以判断最终收敛，但足以否定“直接候选拼接会立即稳定改善 PPO”的假设。

## 8. 证据边界

### 可以写入结论

- 当前价值头在结构上不读取候选集合；
- 当前历史编码近似排列不变；
- 多种真实小图上，128×1 已能学习接近饱和的最优动作；
- 候选感知价值头跨图稳定降低精确价值 MSE；
- 128×1 相比 384×3 具有显著参数和 CPU 吞吐优势；
- 完整图短 PPO 中候选感知效果高度依赖随机种子，尚不能替换主结构。

### 暂时不能声称

- 128×1 的最终 PPO 上限高于 384×3；
- 候选感知结构能提高完整图最终胜率；
- 约 85% 的 PPO 对 Q-table 胜率是游戏理论上限；
- 单张精确子图或单个随机种子代表完整成语图；
- 对 Random 胜率可以单独充分排序策略强弱。

## 9. 建议的下一版模型

不建议直接使用“拼接候选均值后完全替换价值头”的版本。更稳妥的候选分支应：

1. 保留原价值路径；
2. 候选分支作为残差修正；
3. 残差系数初始化为 0 或很小；
4. 候选 embedding 默认 stop-gradient，避免价值损失扰动共享策略 embedding；
5. 单独记录基础价值和候选修正量。

建议形式：

$$
b_t=f_{\text{base}}(z_t),
$$

$$
c_t=f_{\text{candidate}}(z_t,\operatorname{stopgrad}(\bar e_A),\log(1+|A|)),
$$

$$
V(s_t)=\tanh(b_t+\alpha c_t),\qquad\alpha_0=0.
$$

概念伪代码：

```python
state = encoder(current, history, history_mask, player)
candidate_pool = masked_mean(candidate_embeddings, candidate_mask).detach()
candidate_count = log1p(candidate_mask.sum(dim=1, keepdim=True))

base_logit = base_value_head(state)
delta_logit = candidate_delta_head(
    concat(state, candidate_pool, candidate_count)
)
value = tanh(base_logit + alpha * delta_logit)
```

该结构允许训练从原价值模型开始，再逐渐学习候选修正，而不是在初始化时改变整个价值几何。

## 10. 服务器端下一阶段实验计划

### 10.1 最小实验矩阵

| 编号 | 模型 | 目的 |
|---|---|---|
| A | 128×1 原结构 | 小网络基线 |
| B | 128×1 直接候选拼接 | 复现本轮候选版本 |
| C | 128×1 残差候选 + stop-gradient | 推荐结构 |
| D | 384×3 当前结构 | 容量对照；资源允许时运行 |

### 10.2 建议预算

第一阶段：

- 3 个随机种子；
- 300 轮；
- 每轮 64 局；
- 每 50 轮保存 checkpoint；
- 相同 curriculum、相同起始节点流和相同评估起点。

第二阶段仅对第一阶段稳定模型扩展到正式预算。

### 10.3 评估矩阵

每个 checkpoint 至少报告：

- 对 Random 和固定 Q-table，先手/后手分层；
- A/B/C 之间的循环锦标赛；
- 对 iteration 1500 正式 checkpoint；
- 平均对局长度和长度分位数；
- 历史长度超过 64 的状态比例与截断比例；
- value loss、explained variance 和 value calibration；
- entropy、KL、clip fraction 和 grad norm；
- 吞吐量和峰值显存。

评估应复用固定起始成语集合并给出 Wilson 区间。模型间直接比赛要交替先后手。

### 10.4 建议通过条件

候选残差版本进入正式训练前，应同时满足：

1. 至少 2/3 种子对 128×1 基线直接胜率高于 50%；
2. 汇总直接对局区间不支持明显劣化；
3. 对 Q-table 的平均胜率不低于基线；
4. value calibration 或 explained variance 有一致改善；
5. 训练时间和显存增幅可接受；
6. 没有更高的 KL、梯度爆炸或策略熵过快坍缩。

如果只改善监督 MSE、但不改善固定对手和直接对局，应拒绝合并。

## 11. 复现注意事项

- 本轮实验读取 Git 提交中的干净 `idiom.json` blob；服务器运行前应校验 JSON 完整性；
- 正式比较应记录 commit SHA、配置、随机种子、PyTorch/CUDA 版本；
- 不应从同一张图的多个状态划分夸大独立样本数；
- PPO 是 on-policy，不能简单共享另一模型生成的轨迹作为严格等价训练数据；
- 即使复用随机流，模型策略分岔后访问状态仍会不同；
- checkpoint 恢复必须同时恢复 optimizer、scheduler、iteration 和 curriculum 状态。

## 12. 当前决策

- 暂不修改或替换 iteration 1500 正式模型；
- 将 128×1 作为高性价比的服务器消融基线；
- 将残差、stop-gradient 候选价值分支作为下一研究版本；
- 在完整图多种子中确认胜率与训练稳定性后，再决定是否修改正式模型；
- 不再以单图、单种子或单一 Random 对手结果作为模型结构结论。
