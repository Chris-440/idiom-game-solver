# 85% 胜率上限：前因后果

## 问题

纯自博弈训练的模型 vs Q-table，胜率收敛在 **~85%**，无法继续提升。这是模型能力的瓶颈，还是游戏本身的数学上限？

## 实验设计

对 2000 个随机起始成语，每个位置打两局：
- 一局模型先手（P0）
- 一局模型后手（P1）

对手固定为 Q-table，双方均用确定性策略。同时记录 Q-table vs Q-table 的结果作为对照。

## 数据

### 按胜负分类

| 类型 | 数量 | 占比 |
|------|------|------|
| 双边都赢 | 1394 | 69.7% |
| 只能先手赢 | 455 | 22.8% |
| 只能后手赢 | 151 | 7.5% |
| 双边都输 | 0 | 0% |

```
模型先手胜率: 0.924
模型后手胜率: 0.772
总体: (0.924 + 0.772) / 2 = 0.848
```

### 交叉验证：Q-table vs Q-table

对"只能先手赢"和"只能后手赢"的位置，用 Q-table 自对弈判断先手优势是否为游戏本质：

| 位置类型 | QT-QT P0 赢 | QT-QT P1 赢 |
|----------|------------|------------|
| 只能先手赢 (455) | **427 (93.8%)** | 28 (6.2%) |
| 只能后手赢 (151) | 13 (8.6%) | **138 (91.4%)** |

## 推理

"只能先手赢"的 455 个位置中，**93.8%** 在 Q-table 自对弈中也是先手必胜。说明这些位置的先手优势是游戏结构决定的，不是模型不够强——换成 Q-table 走后手同样赢不了。

反之，"只能后手赢"的 151 个位置中，**91.4%** 在 Q-table 自对弈中也是后手必胜，同样是游戏本质。

## 理论上限计算

假设单边赢的位畾无法被任何策略翻盘（被 QT-QT 数据支持）：

```
双边赢位畾: 1394 × (2/2) = 1394.0   ← 两边都能赢，贡献满分
先手必胜:    455 × (1/2) =  227.5   ← 只能赢先手，贡献半分
后手必胜:    151 × (1/2) =   75.5   ← 只能赢后手，贡献半分
─────────────────────────────────
总分:                       1697.0

除以 2000 个位置: 1697.0 / 2000 = 0.8485
```

**理论上限 ≈ 84.9%。**

## 剩余空间

455 个"只能先手赢"的位置中，有 28 个（6.2%）QT 走后手能赢而模型不能。如果模型把这 28 个也学会走后手：

```
边际提升: 28 × (1/2) / 2000 = 0.007
可达上限: 0.849 + 0.007 = 0.856
```

即最多再从 **84.9% → 85.6%**，不到 1 个百分点。

## 结论

1. **模型 vs Q-table 的胜率上限约为 85%，这是成语接龙游戏的数学性质决定的，不是模型能力不足。**
2. 约 23% 的起始成语存在"先手必胜"结构——先手可以选择一个后手无法应答的成语，无论后手策略多强都无法翻盘。
3. 约 8% 的起始成语存在"后手必胜"结构，原因类似。
4. 模型当前 84.9% 已触及理论上限，仅剩 ~0.7% 的优化空间。
5. 要进一步"打败 Q-table"（在 Q-table 走后手时模型先手也能赢，反之亦然），需要改变游戏规则（如扩大成语库）或引入推理时搜索（MCTS）来发现 Q-table 未见过的必胜路径。

## 附录：成语接龙先手优势的成因

成语接龙是一个**确定性的、完美信息的、有限步数的**两人零和游戏。先手优势的来源：

- 先手可以从 26,108 个成语中选择起始点
- 如果先手选了一个"末字生僻"的成语（如以"囔"、"嚅"结尾），后手可能无成语可接，直接判负
- 这种"一步杀"的位置天然偏向先手
- Q-table 的策略是最大化 Q 值（最短路径逼死对手），模型学到了类似的但更强的策略
- 两个强策略对撞时，先手方天然占优
