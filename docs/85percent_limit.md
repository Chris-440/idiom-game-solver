# 重新审视约 85% 的基准平台期

> 文件名保留历史命名，本文不再把 85% 称为经过证明的“游戏理论上限”。

## 观察

纯自博弈 PPO 对固定 Q-table 的确定性评估长期稳定在约 84%–86%。最终 checkpoint 在 2,000 个固定起始成语上分别作为 P0 和 P1 对局，得到：

| 指标 | 结果 |
|---|---:|
| PPO 作为 P0 | 92.4% |
| PPO 作为 P1 | 77.2% |
| 两个角色平衡平均 | 84.8% |

按每个起点的两局结果分类：

| PPO 对固定 Q-table 的结果 | 数量 | 占比 |
|---|---:|---:|
| PPO 作为 P0/P1 均获胜 | 1,394 | 69.7% |
| PPO 仅作为 P0 获胜 | 455 | 22.8% |
| PPO 仅作为 P1 获胜 | 151 | 7.5% |
| PPO 两个角色均失败 | 0 | 0% |

这些是策略对策略的经验结果，而不是起始局面的 minimax 分类。

## Q-table 自对弈交叉检查

在“PPO 仅作为 P0 获胜”的 455 个起点上，Q-table 自对弈中 P0 获胜 427 次；在“PPO 仅作为 P1 获胜”的 151 个起点上，Q-table 自对弈中 P1 获胜 138 次。

这表明 PPO 的角色差异与 Q-table 自对弈的角色差异高度相关，是一个值得进一步研究的结构性信号。但它不能推出：

- P0 或 P1 在这些局面具有必胜策略；
- 另一角色对任意策略都不可能获胜；
- PPO 已达到真实最优策略；
- 84%–86% 是任何模型都无法突破的数学上限。

原因是 Q-table 本身是忽略完整历史的近似策略。近似策略的自对弈胜者不等同于博弈的 minimax 胜者。

## 当前可以支持的结论

1. PPO 对当前固定 Q-table 的表现存在稳定平台期。
2. 该平台期对先后手角色敏感，PPO 作为 P0 明显更强。
3. Q-table 自对弈显示类似的角色相关性，因此差异不太可能只是一次评估噪声。
4. 当前证据不足以区分“游戏结构限制”“双方策略的共同偏差”和“模型能力瓶颈”。

推荐表述：

> PPO 对固定 Q-table 的确定性对局胜率稳定在约 85%。起点级交叉分析显示，该平台期与先后手角色高度相关；由于 Q-table 与 PPO 均为近似策略，这一结果不能视为 minimax 最优性或游戏理论上限的证明。

## 如何得到更强的理论结论

### 1. 精确可解子图

抽取不同规模、不同环结构的小型连通子图，使用完整状态 $(u,U)$ 的 Minimax 或动态规划求得真实胜负值，然后报告策略准确率、value head 校准误差、策略 regret，以及 P0/P1 分层结果。

### 2. 可证明上下界

对无法完全求解的中型图，使用限深搜索、证明数搜索或状态压缩建立可验证的胜负界。只有当策略达到已知上界时，才可以使用“达到上限”一类措辞。

### 3. 多对手与 exploitability

至少加入多个独立随机种子的 Q-table、历史 PPO checkpoint、MCTS、神经网络引导 MCTS，以及专门寻找模型弱点的 best-response 近似器。

### 4. 统计报告

当前 2,000 个起点来自固定随机种子，具有可复现性，但仍应补充多组独立起点、多个训练随机种子、checkpoint 选择与最终测试集隔离，以及配对和角色分层置信区间。

## 关于 MCTS

MCTS 可能提高 PPO 对 Q-table 或其他近似策略的胜率，因为它能在推理时修正静态策略网络的局部错误。但如果未来获得了真实 minimax 上界，任何搜索方法都不可能“突破”该上界。

更准确的研究问题是：

> 在相同推理预算下，神经网络引导搜索能否降低策略 regret、提高跨对手稳健性，并缩小与精确可解子图最优策略的差距？
